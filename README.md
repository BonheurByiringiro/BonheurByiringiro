### 🚀 Featured Projects

#### 🗣️ KinyaLM — Kinyarwanda LLM Fine-Tuning
*Graduate AI Coursework, 2026*
- Fine-tuned **Gemma 4 12B** for Kinyarwanda with **4-bit QLoRA** adapters: compared candidate base models, built a reviewed **3,858-row** targeted training curriculum, and ran a two-stage training pipeline (1,560 cumulative steps)
- Built a controlled evaluation: 150 identical prompts per candidate, blinded model-judge scoring, side-by-side comparison against the base model, with pinned model and data revisions for reproducibility
- Targeted adapter outperformed earlier versions and improved on the base model in sentence correction, Kinyarwanda-to-English translation, and grammar

#### 🔍 [Real or AI](https://github.com/BonheurByiringiro/real-or-ai) — Media & Claim Verification Platform
- A verification platform that returns **two independent verdicts** per submission — media (authentic / synthetic / edited / unknown) and claim (supported / false / misleading / unverified) — backed by retrieved evidence, not just a detector score
- Evidence-only verifier agent with guardrails, an eval harness with teaching cases, and CI (13 tests passing)
- Built on the Meta Model API (Muse Spark)

#### 📊 Predictive Modeling & Data Analysis — Election Forecasting
*Graduate AI Coursework, 2026*
- Developed a **neighbor-sampling neural network in Python** to forecast U.S. election outcomes at the census-block level
- Pulled census and voting data through external APIs and performed end-to-end data processing, feature engineering, and model validation on multi-state datasets

#### 👾 [PACMAN-Game](https://github.com/BonheurByiringiro/PACMAN-Game) — Automated PAC-MAN AI
- Automated PAC-MAN AI project built with classic AI search algorithms and Pygame

#### 🛍️ TONA.rw — Premium Baby Boutique (Kigali)
- Full-stack e-commerce store built in **Python / Django + MySQL** for a real shop in Kigali, Rwanda — catalogue, cart, checkout, delivery zones, VAT handling, owner/manager roles, and an installable PWA
